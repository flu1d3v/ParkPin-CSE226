# ParkPin

Campus parking spot tracker for CSE226 group project.

## Problem Statement
P07 - ParkPin: App to save and navigate back to a parking spot on campus.

## Overview
ParkPin lets users mark their current parking location with a single tap and 
navigate back to it later using Google Maps. The app also includes an AI-based 
image labeling feature that tags the surroundings of a parking spot to help 
users recall its location more easily.

## Features
- Mark current parking spot using GPS
- Navigate back to saved spot via Google Maps
- View history of previously saved spots
- AI image labeling (Google ML Kit) - auto-tags surroundings from a photo 
  taken at the parking spot

## Tech Stack
- Kotlin
- Android Jetpack (Room Database, ViewModel)
- Google Maps SDK / Location API
- Google ML Kit (Image Labeling)
